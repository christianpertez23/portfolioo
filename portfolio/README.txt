HOW TO RUN (XAMPP / PHP 8+)
1. Copy your  image/  video/  origami/  folders into this folder (next to index.php).
2. Put this folder in C:\xampp\htdocs\
3. XAMPP Control Panel: Start BOTH Apache and MySQL.
4. Open http://localhost/portfolio/ . The database "portfolio_db" and its tables are created automatically.
5. Log in > Create one. The FIRST account becomes admin.
View the data at http://localhost/phpmyadmin  >  portfolio_db  >  users / messages.
Database settings: includes/config.php
